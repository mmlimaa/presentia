⚠️ Lições Aprendidas do Deploy (Evitar Retrabalho)
wsgi.py: Deve sempre apontar para config.settings.production no GitHub.

production.py: Nunca deve ir para o GitHub. Se o git reset --hard for rodado, ele não apagará o production.py local da VPS, desde que o arquivo não esteja no rastreamento do Git.

Sessões: Para evitar que o login caia no meio da navegação com múltiplos workers do Gunicorn, configuramos SESSION_ENGINE = "django.contrib.sessions.backends.cache" com LocMemCache no production.py.

Comandos de Deploy:

No PC: git add . && git commit -m "..." && git push origin main

Na VPS: cd /var/www/presentia && git fetch origin && git reset --hard origin/main && sudo systemctl restart presentia
